SuperNumber Lab 使用说明

      
    
        
  • 常量：添加时弹出配置（定宽整数位宽/符号、大整数、浮点 E/M/NaN、复数）。双击节点可再编辑。定宽/浮点有 i32、FP64 等预设；E/M 可任意大。
    • 
        
  • 连线：从任意端口拖到另一端（输出↔输入均可）。数据口与执行口（exec）不可互连，也不会错误高亮。类型不匹配会自动插入 Cast。松手在高亮圆点上即可连线。Esc 取消。
    • 
        
  • 边缘自动平移：连线或拖动（含框选批量移动）靠近工作区边缘时，画布自动向该方向平移，便于把节点移到视野外区域（类似 UE 蓝图）。
    • 
        
  • 移动节点：按住标题栏拖动；松手即停。支持 框选 后批量移动。Shift/Ctrl 点选多选。
    • 
        
  • 撤销 / 重做：工具栏按钮，或 Ctrl+Z / Ctrl+Y（Mac 可用 Cmd）。
    • 
        
  • 画布平移 / 缩放：中键拖拽平移；或按住 空格（或 Alt）+ 左键；滚轮平移视图；Ctrl+滚轮 缩放；触控板/手机 双指 平移与捏合缩放。
    • 
        
  • 注释：独立「注释」节点；也可在节点旁附加注释（右键 / 配置，类似 UE 节点备注）。
    • 
        
  • 自定义函数：「函数」页签 → 新建 / 编辑 / 重命名 / 删除 → 在函数画布内用参数/返回节点搭子图 → 主画布「放入画布」或拖入调用。调用节点带 exec 进/出，可串入控制流。参数最多 64，可缺省（未用到的可不连）。
    • 
        
  • 运行：工具栏「运行」或 Enter。所有运算走 SN/WASM，保证与原生一致。节点结果预览最多两行（首尾摘要 + 省略号），悬停看全文。
    • 
        
  • 工程：JSON 导入/导出（非空工程导入会询问）；「导出 C」生成标准 sn_api 调用；右侧可预览导出的 C 代码（语法高亮）。
    • 
        
  • 右键菜单：在画布空白 / 节点 / 连线上右键，可运行、复制粘贴、断开连线、折叠端口、导出等。
    • 
        
  • 本地：modular 需 HTTP；单页 snlab-single.html 可 file://。
    • 
      


      
控制流（UE 蓝图风格）

      
    
        
  • Entry：执行起点；有 Entry 时按 exec 白线解释执行，否则按纯数据拓扑求值。
    • 
        
  • Branch / If：cond 真走 then，假走 else。
    • 
        
  • While / For / DoWhile：循环体走 body，结束后走 completed；While 可设 max_iter。
    • 
        
  • Set / Get：局部变量，配合循环可搭密码学迭代（mulmod/powmod 等）。
    • 
        
  • Print / Output：带 exec 进/出；有 Entry 时只走 exec 路径上的输出。
    • 
        
  • DoOnce / DoN / Gate / FlipFlop / MultiGate / Switch：流程控制；Break/Continue 作用于最近循环。
    • 
        
  • 端口内联字面量：未连线的数据口可在节点内直接填值；已连线则隐藏输入框。
    • 
        
  • 浮点预设：FP16 / FP32 / FP64 / FP128 等；E/M 仍可任意手改。
    • 
        
  • 端口折叠：标题栏折叠钮优先隐藏未连接的数据端口；仍可整节点折叠。
    • 
        
  • 数组 / 向量 / 矩阵 / Tensor：Make / Get / Set / MatMul / Attention / LayerNorm 等，运行时走 SN。
    • 
        
  • 示例：RSA、Qwen3 toy、Transformer toy、数组求和等可从示例加载。
    •
